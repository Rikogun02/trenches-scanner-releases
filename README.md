# Trenches Scanner — Unduhan Android

Halaman resmi unduhan APK **Trenches Scanner**, aplikasi Android untuk memantau koin baru pump.fun (Solana) secara real-time, menyaring token berisiko, dan mengirim notifikasi ke HP.

## Unduh

➡️ **[Unduh versi terbaru](../../releases/latest)** — pilih file `trenches-scanner-vX.Y.Z.apk`.

## Cara pasang

1. Unduh file APK dari halaman Releases di atas.
2. Buka file tersebut di HP, lalu izinkan **Instal aplikasi tidak dikenal** bila diminta.
3. Buka aplikasi → izinkan notifikasi → tekan **Mulai scan**.
4. Disarankan: matikan optimasi baterai untuk aplikasi ini agar scan tidak dihentikan sistem.

## Update

Aplikasi mengecek repositori ini saat dibuka dan setiap 6 jam selama scan berjalan. Jika ada versi baru, muncul pemberitahuan dan Anda bisa langsung **Unduh & pasang update** dari dalam aplikasi.

## Verifikasi keaslian

Semua APK resmi ditandatangani dengan sertifikat berikut:

```
SHA-256: a9:4d:7d:bf:92:c2:af:75:b4:68:cd:76:4a:2b:80:25:45:8c:bd:0f:f6:6f:d5:7e:dc:81:5f:ed:1e:e5:e7:0f
```

Cek dengan: `apksigner verify --print-certs trenches-scanner-vX.Y.Z.apk`

## Catatan

- Aplikasi ini **hanya scanner/alert**: tidak melakukan trading dan tidak meminta private key atau seed phrase. Jangan pernah memasukkan seed phrase ke aplikasi apa pun.
- Memecoin sangat berisiko. Skor dari aplikasi bukan jaminan dan bukan saran keuangan.
- Repositori ini hanya berisi file rilis; kode sumber dikelola terpisah.
